# ก้อนกล้าม · แอปฝึกของฉัน

เว็บแอปจัดตารางฝึก ใช้ GitHub Pages เป็นที่อยู่แอป และ Firebase เก็บข้อมูลกับล็อกอินด้วย Google (ฟรีทั้งคู่)

## ไฟล์ในโฟลเดอร์

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `index.html` | ตัวแอปทั้งหมด |
| `firebase-config.js` | ค่าของโปรเจกต์ Firebase (ต้องแก้ ขั้นที่ 1) |
| `firestore.rules` | กฎความปลอดภัย ให้แต่ละคนเห็นแค่ข้อมูลตัวเอง (ขั้นที่ 1) |
| `manifest.json`, `sw.js`, `icon-*.png` | ทำให้กด "เพิ่มลงหน้าจอโฮม" ได้ และเปิดได้ตอนไม่มีเน็ต |
| `.nojekyll` | บอก GitHub Pages ให้ส่งไฟล์ตามที่เป็น |

## เริ่มใช้งาน (รวมประมาณ 20 นาที)

ทำตามคู่มือ **[docs/FIREBASE-SETUP.md](docs/FIREBASE-SETUP.md)** ทีละข้อ (ใช้มือถือ/แท็บเล็ตไม่มีคอม ดู **[docs/MOBILE-SETUP.md](docs/MOBILE-SETUP.md)**)

1. สร้างโปรเจกต์ Firebase แล้วเปิดล็อกอิน Google กับ Firestore
2. ใส่ค่าในไฟล์ `firebase-config.js`
3. อัปโหลดขึ้น GitHub แล้วเปิด Pages
4. อนุญาตโดเมน `ชื่อผู้ใช้.github.io` ใน Firebase
5. ย้ายข้อมูลจากแอปเดิมใน Claude (สำรองข้อมูล → นำเข้าข้อมูล)

ไอเดียที่จะทำต่อ: **[docs/BACKLOG.md](docs/BACKLOG.md)**

## ใช้บนมือถือ

- **iPhone:** เปิดลิงก์ใน Safari → ปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม**
- **Android:** เปิดใน Chrome → เมนู ⋮ → **ติดตั้งแอป** / **เพิ่มลงในหน้าจอหลัก**

## ข้อควรรู้

- ไม่ล็อกอินก็ใช้ได้ ข้อมูลจะอยู่ในเครื่องนั้นเท่านั้น ถ้าล้างเบราว์เซอร์ข้อมูลจะหาย
- ล็อกอินแล้วข้อมูลซิงก์ทุกเครื่อง บันทึกตอนไม่มีเน็ตได้ แล้วจะส่งขึ้นเองเมื่อเน็ตกลับมา
- แพ็กเกจฟรี (Spark) ไม่ต้องผูกบัตร ถ้าใช้เกินโควตา บริการจะหยุดชั่วคราว ไม่มีค่าใช้จ่าย
- ข้อมูลของแต่ละคนเก็บเป็นเอกสารเดียว `users/{uid}` รองรับประวัติได้หลายร้อยครั้ง ถ้าใช้ไปนานมากค่อยแยกประวัติเป็นคอลเลกชันย่อย
- อัปเดตแอป: อัปโหลด `index.html` ตัวใหม่ทับใน GitHub แล้วเปิดแอปใหม่ 1–2 ครั้ง
