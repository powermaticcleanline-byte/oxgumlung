# ไอเดียที่จะทำต่อ

## ทำแล้ว ✅
- แนะนำน้ำหนักครั้งหน้า
- ตัวคำนวณแผ่นน้ำหนัก
- แอนิเมชันสอนท่า (Squat, Bench Press, Lat Pulldown)
- ความสำเร็จ ไฟฝึกติดกัน XP มิชชั่น เหรียญ
- หน้าแนะนำแอป 3 หน้า + แก๊งพาเหรดหน้าล็อกอิน
- ต่อ Firebase + GitHub Pages (รอตั้งค่า)

## ทำได้เลย (ใช้ข้อมูลที่มีอยู่)
- [ ] บอสประจำสัปดาห์ (ทุกเซตคือการโจมตี ปริมาณที่ยก = ดาเมจ)
- [ ] วอร์มอัพอัตโนมัติ
- [ ] ประมาณค่า 1RM พร้อมกราฟ
- [ ] แผนที่กล้ามเนื้อพิกเซล
- [ ] คะแนนความล้า/ฟื้นตัวของกล้าม (แดง → เขียว 2–3 วัน)
- [ ] ปฏิทินสะสมแสตมป์ + เหรียญรายเดือน
- [x] ไข่อีสเตอร์ (จิ้ม 10 ครั้งน้องโกรธ, เปิดตี 3 น้องนอนกรน)
- [ ] โปรแกรมสำเร็จรูป (PPL, Upper/Lower, Full body 3 วัน, มือใหม่)
- [ ] แอนิเมชันสอนท่าเพิ่มทีละกลุ่มการเคลื่อนไหว

## งานเยอะหน่อย
- [ ] น้องโตตามเลเวล
- [ ] ตู้เสื้อผ้า (แลกด้วย XP)
- [ ] อารมณ์น้องตามพฤติกรรม (งอนเมื่อหายไปหลายวัน)
- [ ] ชุดตามเทศกาล (สงกรานต์ ลอยกระทง ปีใหม่)
- [ ] กาชาหลังฝึก (ของแต่งตัว/คำคม ไม่ใช้เงินจริง)
- [ ] เพลงชิปทูน 8-bit ตอนพัก + เสียงแบบเกม
- [ ] การ์ดสรุปการฝึก 8-bit ไว้แชร์ลงสตอรี่
- [ ] โหมดคาร์ดิโอ interval (HIIT/Tabata) น้องนับถอยหลัง
- [ ] โหมดวันพัก มินิเกมยืดเหยียด 5 นาที

## ต้องมี Firebase ก่อน
- [ ] บัดดี้ฝึก (เห็นไฟของเพื่อน ส่งน้องไปสะกิด)
- [ ] ปาร์ตี้ล่าบอส 3–4 คน
- [ ] ลีก XP รายสัปดาห์
- [ ] รูปก่อน-หลัง (เก็บแบบส่วนตัว)

## อนาคต

## รอบ 3 (โน้ตไว้ 24 พ.ย. 2026)
- ข้อความลับจากแฟน: ปลดล็อกเมื่อถึงเป้า กดค้างที่ตัวละครเพื่ออ่าน
- ปุ่ม "ข้ออ้างวันนี้": น้องโต้กลับแบบกวน ถ้าป่วยหรือปวดเมนส์เปลี่ยนเป็นโหมดใจดี
- เขย่ามือถือเพื่อสุ่มท่า
- ให้อาหารน้อง (โปรตีนเชค) ไม่ฝึกนานน้องผอมและงอน
- ถามอารมณ์หลังฝึก (สบาย / เหนื่อย / ตายแล้ว) แล้วเก็บเป็นสถิติ
- ระบบ: แยกเก็บประวัติทีละการฝึก, รวมข้อมูลเมื่อใช้สองเครื่อง, แจ้งเวอร์ชันใหม่, หน้าเริ่มต้นครั้งแรก, ปุ่มส่งความเห็น, ลบบัญชี, นโยบายความเป็นส่วนตัว, หน้าทดสอบแยก
